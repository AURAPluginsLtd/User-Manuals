Thank you for your interest towards our Editor & Librarian software.

We built our Access Virus Editor to control Virus A, Virus B, Virus Rack, Virus C, Virus Rack XL, Virus TI, Virus TI Snow and Virus TI2 models over MIDI or USB. Connect MIDI input & output, Audio jack cables to mixing console / sound card and fire up your Computer to get started! You can also use the USB even if you are using macOS 10.12 or greater!

Access Virus Editor User Manual contains instructions to get the Editor installed and configured. Please read this manual through carefully. Any feedback with comments on how to improve the documentation is welcomed.
