# If I place preorder for upcoming Editor product, will I have access to BETA version?

Yes. We will provide BETA version as soon as it is ready for testing. Sometimes BETA staging can take a bit longer, but we are on it when pre-order is available.

BETA access is restricted to users who has joinded or [Discord](https://discord.gg/TeG7ukYcVW) server to keep the testing and validation managed
