# How do I add the license for the Editor to register?

**[ Recommended: AURA Plugins Download Manager ]**

The **AURA Plugins Download Manager** adds the license for you. There is nothing to rename or copy.

1. Download AURA Plugins Download Manager for [macOS](https://downloads.auraplugins.com/download/aura-plugins-download-manager-mac/) or [Windows](https://downloads.auraplugins.com/download/aura-plugins-download-manager-pc/), install it and open it.
2. **Sign in** with your AURA Plugins account email and password.
3. Install the full version of your Editor with **Install** or **Get full version**.
4. The Download Manager writes the license into the Editor data folder after the install, and refreshes it each time you sign in.
5. Reload your project or plug-in instance in order to validate.

> **NOTE:** The license is written only for Editors that have a plug-in format or the App installed. Installing only the user manual does not add a license.

**Manual license install**

UPDATE 2023-August-28

**[ Korg MS2000 & Korg microKorg ]** license.key needs to be located in:

```
[ WINDOWS ] ”login username”\Documents\Mystery Islands Music\”plug-in name”
```

```
[ macOS ] /Library/Audio/Presets/Mystery Islands Music/”plug-in name”/
```

…in order to register. Reload your project or plug-in instance in order to validate.

**[ All other editors ]**

Downloaded license.key must be renamed to “(plugin name).license” and placed in: **~/Music/AURA Plugins/(editor name)/** folder.

To make this easy, click on “register” text in the top left corner to open the file browser dialog and open the license file with it. Rest will be automated.
