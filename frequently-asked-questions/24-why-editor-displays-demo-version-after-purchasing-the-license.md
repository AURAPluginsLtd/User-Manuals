# Why Editor displays DEMO version after purchasing the license?

You need to download and install the FULL version of our Editor in order to register it. The easiest way is the **AURA Plugins Download Manager**, which installs the full version and the license for you.

1. Download AURA Plugins Download Manager for [macOS](https://downloads.auraplugins.com/download/aura-plugins-download-manager-mac/) or [Windows](https://downloads.auraplugins.com/download/aura-plugins-download-manager-pc/), install it and open it.
2. **Sign in** with your AURA Plugins account email and password. If you skipped sign-in earlier, click **Login** in the sidebar.
3. Your Editor card shows **Get full version** when the DEMO is installed and your account owns the Editor. Click it.
4. Click **Install** for the formats you use. The full version replaces the DEMO.
5. The Download Manager writes the license automatically. Re-open the Editor to validate the license.
6. When validation succeeds, the Editor says “Registered” in the top left corner.

> **NOTE:** Full version install needs an active membership for that Editor on the account you sign in with.

**Manual install from the store**

Head down to [https://auraplugins.com/my-account/](https://auraplugins.com/my-account/) (login if prompted) – Navigate to the downloads page and select the product you want.

1. Download the full installer and license.
2. Install full version.
3. Check license instructions and install license.
4. Re-open the Editor to validate the license.
5. When validation succeeds, the Editor says “Registered” in the top left corner.
