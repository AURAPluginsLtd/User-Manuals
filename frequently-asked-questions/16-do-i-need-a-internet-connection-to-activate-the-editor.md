# Do I need a internet connection to activate the Editor?

No, the Editor itself does not need an internet connection to activate.

On a computer that is online, the easiest way is the **AURA Plugins Download Manager** ([macOS](https://downloads.auraplugins.com/download/aura-plugins-download-manager-mac/) / [Windows](https://downloads.auraplugins.com/download/aura-plugins-download-manager-pc/)). **Sign in**, install the full version, and the Download Manager adds the license for you. You can also **Skip, use demos** to try the DEMO versions first.

For an offline computer, you can purchase the Editor license from our store and download the license.key + full installers from [https://auraplugins.com/my-account/](https://auraplugins.com/my-account/) and take them to your offline computer for setup.

Internet connection has advantages like automated update check which usually is something that improves the Editor usage!
