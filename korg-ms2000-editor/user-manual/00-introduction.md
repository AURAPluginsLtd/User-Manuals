# Introduction

![Korg MS2000 Editor Main](images/korg-ms2kxr-main-interface-v2.jpg)

Thank you for your interest towards our Editor & Librarian software.

We built our Korg MS2000 Editor to control MS2000 / MS2000R and MS2000B / MS20000BR models over MIDI. Modern synths come up with an integration tool to hook your synth into DAW and we wanted to give this same opportunity to you as well. Connect MIDI input & output, Audio jack cables to mixing console / sound card and fire up your Computer to get started!

Korg MS2000 Editor User Manual contains instructions to get the Editor installed and configured. Please read this manual through carefully. Any feedback with comments on how to improve the documentation is welcomed.
