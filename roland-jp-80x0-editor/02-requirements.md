# Roland JP-80×0 Editor – Requirements

## Hardware Requirements

- Roland JP-8000 or Roland JP-8080 Synthesizer

MIDI Interface that can handle System Exclusive messages.

- ESI MidiMate eX has proven to be good
- Roland UM-ONE mkII has proven to be good

**ATTENTION** : Cheap 1 In and 1 Out MIDI-USB cables might not pass System Exclusive messages to the hardware, so check the compatibility from the manufacturer before you make the purchase!

## Computer Requirements

- **Mac**: macOS 10.12 or greater with AAX, Audio Unit, VST2 or VST3 host application.
    - Standalone Application works without host application.
    - Metal compatible GPU.
- **PC**: Windows 7 or greater with AAX, VST2 or VST3 host application.
    - Standalone Application works without host application.
- Intel or Apple Silicon processor.
- At least FULL HD resolution on your display.

## Plug-in Compatibility

## Available plug-in formats (64-bit only)

- AAX (native)
- AudioUnit (macOS only)
- VST2
- VST3
- Application

## Currently supported host applications

- Ableton Live
- Apple Logic
- Bitwig Studio
- Cockos Reaper
- Image Line Fruity Loops
- Presonus Studio One
- Reason Studio Reason
- Steinberg Cubase
- Renoise
- MOTU Digital Performer
- AVID Pro Tools
- Universal Audio Luna

We haven’t tested other hosts, but if your host can load the plug-in formats mentioned above, you should not have any issues loading our plug-in.

If there is an error with the plug-in on your host, let us know and we will make it work.
