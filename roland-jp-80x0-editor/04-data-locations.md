# Roland JP-80×0 Editor – Data Locations

If you have overwritten any of the included sound banks with a previous version of the Editor, it is worth renaming those sound banks in order to prevent data overwriting once Editor updater is executed.

Editor **data / license** folder is:

```
~/Music/AURA Plugins/Roland JP-80x0 Editor/
```

Roland JP-80x0 **Patch** and **Performance** folder is:

```
~/Music/AURA Plugins/Roland JP-80x0 Editor/Patches/
```
