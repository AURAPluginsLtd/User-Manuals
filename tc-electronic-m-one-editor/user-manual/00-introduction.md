# Introduction

![v251127 m one editor main](images/v251127-m-one-editor-main.jpg)

Thank you for your interest towards our Editor & Librarian software.

We built our TC Electronic M-One Editor to control M-One and M-One XL effect over MIDI. Modern synths come up with an integration tool to hook your synth into DAW and we wanted to give this same opportunity to you as well. Connect MIDI input & output, Audio jack cables to mixing console / sound card and fire up your Computer to get started!

TC Electronic M-One Editor User Manual contains instructions to get the Editor installed and configured. Please read this manual through carefully. Any feedback with comments on how to improve the documentation is welcomed.
